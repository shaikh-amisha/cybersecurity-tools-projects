# Nmap Labs

This folder contains hands-on Nmap exercises and network-scanning write-ups.

## Labs

1. [Lab 01: Nmap Scanning and Output Analysis](Lab-01-Nmap-Scanning-and-Output-Analysis.md)
   - Scan localhost on a specific port
   - Understand port states and service identification
   - Verify an HTTP service with curl

2. [Lab 02: Save Nmap Output to XML](Lab-02-Save-Nmap-Output-to-XML.md)
   - Save scan results in XML format
   - Understand the `-oX` option and correct command syntax
   - Inspect the generated report

Each write-up documents the objective, environment, commands, command explanations, observed results, and key learnings.

Only scan systems you own or have explicit permission to test.
