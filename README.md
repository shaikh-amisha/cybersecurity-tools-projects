## Documentation Approach

Each lab write-up will describe its objective, authorized lab environment, methodology, commands, observations, findings, and lessons learned. Screenshots may be included where useful.

> All testing is performed in authorized lab environments. Sensitive information, credentials, tokens, and protected challenge flags are not published.
